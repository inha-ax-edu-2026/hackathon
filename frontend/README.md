# Frontend

2026 INHA AX-EDU 해커톤 출품작의 사용자 화면입니다. (React + TypeScript + Vite)
학생이 AI 챗봇에게 고민을 털어놓다가 선생님 상담으로 이어지고, 교사가 요약·위험도·사후 서류를 확인해 승인하는 흐름을 보여 줍니다.

## 요구 사항

- Node.js 20.19+ (개발 환경: Node 26)
- npm
- 시연 브라우저: **PC의 Chrome**. 주소는 `localhost`, 인터넷에 연결돼 있어야 합니다.
  학생의 음성 입력(마이크)은 Chrome 내장 음성 인식을 쓰므로 인터넷이 필요하고, 마이크 권한을 허용해야 합니다.
  음성이 안 돼도 입력창 위 「예시 문장」을 눌러 같은 시연을 할 수 있습니다.

## 설치와 실행

백엔드 없이 목(mock) API만으로 시연됩니다.

```bash
cd frontend
npm install
cp .env.example .env
```

`.env`를 열어 `VITE_USE_MOCK=true`로 바꿉니다. (비어 있어도 `VITE_API_BASE_URL`이 비어 있으면 목 API가 켜집니다. 실제 백엔드를 쓰려면 `VITE_API_BASE_URL`을 넣거나 `VITE_USE_MOCK=false`로 둡니다.)

```bash
npm run dev
```

Chrome에서 http://localhost:5173 을 엽니다.

## 환경변수

| 키                  | 설명                                                                                |
| ------------------- | ----------------------------------------------------------------------------------- |
| `VITE_USE_MOCK`     | `true`면 MSW 목 API를 켜고 `false`면 끈다. 비어 있으면 백엔드 주소가 없을 때만 켠다 |
| `VITE_API_BASE_URL` | 백엔드 API 주소. 목을 쓸 때는 비워 둔다                                             |

## 시연 순서

1. http://localhost:5173 (시연 런처)에서 **시연 초기화**를 누릅니다.
2. **학생 화면 열기**와 **교사 화면 열기**를 눌러 새 탭 두 개를 나란히 띄웁니다. (같은 Chrome 안에서 열어야 두 탭이 데이터를 함께 씁니다.)
   **교사 탭은 학생이 전환되기 전에 열어 둡니다.** 토스트는 교사 화면이 열려 있는 동안 새로 생긴 전환 건에만 뜹니다. 교사 탭을 나중에 열면 그 전에 생긴 전환 건은 토스트 없이 왼쪽 종 배지와 알림 시트에만 보입니다.
3. 학생 탭: **+ 상담 신청하기** → **AI 챗봇 상담** → **다음** → 상담 주제·기분·기간·고민을 적고 **상담 시작하기**.
4. 학생 탭: 마이크로 말하거나 입력창 위 예시 문장을 눌러 **보내기**. 세 번째 발화에서 키워드가 감지되어 「선생님께 전달했어요」 안내가 나옵니다.
5. 교사 탭: 오른쪽 위 토스트를 누르거나 왼쪽 종 아이콘의 새 알림을 눌러 상담 건 상세를 엽니다. 요약·위험도·상담 양식을 확인합니다. (대화 전문은 교사에게 보이지 않습니다.)
6. 교사 탭: 사후 서류 카드에서 서류를 고르고 필요하면 내용을 고친 뒤 **검토 완료**를 눌러 **승인 완료**로 만들고, 오른쪽 위 **상담 승인**을 누릅니다.
7. 학생 탭에 「선생님이 상담을 승인했어요」가 나타나고 상태가 **상담대기**로 바뀝니다.

처음 상태로 되돌리려면 런처(`/`)에서 **시연 초기화**를 다시 누릅니다.

## Vercel 배포

- Root Directory는 `frontend`, Framework Preset은 Vite로 둡니다. (빌드 `npm run build`, 출력 `dist`)
- 환경변수 `VITE_USE_MOCK=true`를 Vercel 프로젝트 설정의 Environment Variables에 넣습니다.
  빠뜨려도 `VITE_API_BASE_URL`이 없으면 목 API가 켜집니다. (목이 꺼진 채 배포되면 Vercel이 `POST /api/...`에 405를 돌려줍니다.)
  `.env`는 커밋되지 않으므로 Vercel 빌드에 들어가지 않고, 값은 빌드할 때 코드에 박히므로 바꾼 뒤에는 재배포해야 합니다.
- `vercel.json`이 모든 경로를 `index.html`로 보내므로 `/teacher/...` 같은 주소를 새로고침하거나 직접 열어도 404가 나지 않습니다.
- 목 데이터는 브라우저 `localStorage`에 저장됩니다. 학생·교사 탭은 같은 브라우저에서 열어야 상담 건이 공유됩니다.
