# 백엔드 연결 · 접속키 없음

일반 모드와 시연 모드 모두 프론트 연동키·교사 접속키를 사용하지 않는다. 실제 모델 호출용 BAZE_API_KEY만 백엔드에서 관리한다.

## 바로 사용

- 현재 공유 서버 주소가 프론트 기본값에 들어 있다. 접속하면 서버 상태와 상담 API를 확인한 뒤 자동으로 화면을 연다.
- 변경한 주소와 실행 모드만 localStorage에 기억한다. 새로고침·새 탭에서도 다시 입력하지 않는다.
- 서버 주소가 바뀌었다면 **연결 설정**에서 주소만 수정한다. /api를 붙이지 않는다.
- 연결 확인에는 유료 AI 호출이 없다. 상담·AI 서류 생성·전사에는 서버 설정에 따라 사용량이 발생한다.
- 서버가 꺼졌거나 주소가 만료되면 연결 오류를 표시한다. **가상 시연 사용**을 선택하면 MSW 응답으로 확인할 수 있다.

## 주소 기본값

`src/lib/api.ts`의 DEFAULT_BACKEND_URL이 현재 기본 주소다. 배포 환경의 VITE_API_BASE_URL이 있으면 그 값을 우선 사용한다. 사용자가 선택한 주소·모드는 다음 접속에도 유지한다.

공유 실행기는 새 주소를 `/?backend=...` 공개 주소 매개변수에 담은 프론트 링크를 자동으로 연다. 프론트는 이를 기억하고 바로 연결하므로 키·주소를 직접 입력할 필요가 없다.

Cloudflare 임시 주소는 공유 실행기를 새로 실행하면 바뀔 수 있다. 고정된 상시 주소가 아니다. 주소 변경 시 연결 설정, 기본값, 또는 Vercel의 VITE_API_BASE_URL 중 사용 중인 값을 갱신한다. Vercel 환경변수 변경은 재배포가 필요하다.

VITE_USE_MOCK 값으로 실제 연결이 꺼지지 않도록 자동 백엔드 연결을 기본으로 한다. 모의 응답은 화면에서 **가상 시연 사용**으로 선택한다.

## 화면·API

기존 디자인의 상담 생성·대화·위험 보고·교사 요약·승인·기존 서류 4종 편집/저장을 유지한다. 모든 요청은 접속키 헤더 없이 호출한다. 남아 있는 예전 접속키 헤더는 전송하지 않는다.

교사 상세의 **사후 서류 → 서류 작업실 열기**는 현재 상담으로 연결한 사안을 재사용하거나 생성한 뒤, 프론트의 `/teacher/school-violence/{id}?tab=documents`로 이동한다. 팀 디자인의 사안 자료·서류 체크리스트에서 1-3·2-4 양식을 열어 고성능 AI 초안 생성·근거 확인·수정·저장·인쇄를 진행한다. 백엔드 `/document-demo`는 내부 점검용이며 이 버튼의 연결 대상이 아니다.

실제 연결에는 `/api/teacher/school-violence/cases` 계열 API가 필요하다. 최신 백엔드로 재시작하면 SQLite에 사안·초안·검토 상태를 보관한다. 시연용으로 미리 붙인 진술서·학폭 처리 중 개별 면담은 실제 연결 상담 요약과 별도 자료로 표시한다. 생성 버튼을 누르면 선택한 가상 자료를 외부 고성능 모델로 전송하며 실제 API 오류를 모의 초안으로 바꾸지 않는다.

접속키가 필요하다는 응답이 나오면 구버전 백엔드가 실행 중인 것이다. 공유 서버 창에서 Ctrl+C 후 backend/start_shared.cmd를 다시 실행한다.

## 검증

AI 초안 생성은 작업 ID를 받은 뒤 짧은 상태 조회로 완료를 확인한다. 2-4처럼 항목이 많은 양식도 긴 연결 하나에 묶이지 않으며, 새로고침 후 진행 중인 작업을 다시 조회한다. 중복 클릭은 같은 작업을 재사용하고 결과는 서버에 자동 저장한다. 생성 작업 API를 모르는 이전 서버에는 재시작 안내를 표시한다.

```bash
npm ci
npm run check
npm run build
```

build는 타입 검사 → Vitest 계약 테스트 → Vite 번들 생성을 실행한다. 실제 학생 자료 대신 가상 자료를 사용한다. 외부 BAZE 인증과 일반 접속키 제거는 서로 별개이며 BAZE 키는 브라우저 코드·응답에 넣지 않는다.
