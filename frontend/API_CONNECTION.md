# 백엔드 API 연결

## 화면에서 입력

1. 런처(`/`) 또는 학생·교사 화면 상단에서 **연결 설정**을 연다. 실제 연결 모드에 접속키가 없으면 연결 화면이 먼저 열린다.
2. **백엔드 주소**: 공유 서버 창에 나온 HTTPS 주소만 넣는다. /api를 붙이지 않는다. 임시 터널을 재실행했다면 새 주소를 넣는다. 로컬 프론트에서는 http://127.0.0.1:8000 같은 loopback 주소도 허용한다.
3. **프론트 연동키**: backend/.env.shared의 FRONTEND_ACCESS_TOKEN 값만 입력한다. 따옴표는 포함하지 않는다.
4. **교사 접속키(선택)**: TEACHER_ACCESS_TOKEN. 입력했다면 교사 보고 조회 API로 확인한다. 현재 학생·교사 상담 계약은 모두 프론트 연동키를 사용한다.
5. **백엔드 연결**을 누른다. /health 계약과 상담 목록 인증을 확인한다. AI를 호출하거나 자료를 변경하지 않는다. 성공하면 기존 상담 화면에서 테스트한다.

BAZE_API_KEY는 프론트에 입력하지 않는다. 접속키는 코드·쿼리 캐시·sessionStorage·localStorage에 저장하지 않고 현재 탭 메모리에만 둔다. 주소와 모드만 sessionStorage에 기억한다. 새로고침·새 탭에서는 키를 다시 입력한다. 학생·교사 탭을 각각 연결하면 같은 서버의 테스트 DB를 공유한다.

같은 서버에서 키 입력란을 비워두면 현재 키를 유지한다. 다른 서버로 바꾸면 키를 새로 입력해야 한다. 잘못된 키·서버 오류가 나면 새 연결을 확정하지 않는다. 실제 상담 오류를 가짜 성공 응답으로 대체하지 않는다.

**가상 시연 사용**은 MSW를 다시 켜고 메모리의 키를 지운다. 주소나 모드가 바뀌면 이전 쿼리·변경 캐시를 비우고 현재 역할의 상담 목록으로 돌아간다. 이미 시작한 옛 연결의 응답은 사용하지 않는다. 키 입력 전에는 상담 화면을 마운트하지 않아 미인증 폴링을 막는다.

이 기능은 가상 자료를 사용하는 팀 시연용이다. 실제 학생/교사별 로그인·운영 권한·슈퍼스쿨 실명 연동을 제공하지 않는다.

## 요청별 인증

| 요청                   | 자동 헤더         |
| ---------------------- | ----------------- |
| /api/student/counsel/* | X-Frontend-Access |
| /api/teacher/counsel/* | X-Frontend-Access |
| /api/demo/reset        | X-Frontend-Access |
| 그 밖의 /api/teacher/* | X-Teacher-Key     |
| /health                | 접속키 없음       |

주소·헤더·JSON·네트워크/비JSON 오류 처리는 src/lib/api.ts에서 관리한다. 외부 URL·상위 경로 이동을 API 경로로 허용하지 않으며 쿠키를 보내거나 인증 요청의 리디렉션을 따르지 않는다.

기존 src/api 훅으로 상담 생성·메시지·교사 전환·종료·승인·요약·서류 수정/검토 완료를 호출한다. 학생 메시지는 응답 ID로 중복 제거해 실패 후 재시도의 중복 표시를 막는다. 모델 선택은 백엔드가 담당하며 프론트에 가성비 선택기를 추가하지 않는다.

## 학교폭력 서류 작업실

실제 연결 상태에서 교사 상세의 **사후 서류** 탭에 **서류 작업실 열기**가 나타난다. 현재 서버 주소의 /document-demo?case_id=...로 연결하며 접속키를 URL에 넣지 않는다. 작업실에서 교사키를 다시 입력한다.

작업실은 이전 상담·학생별 진술서·사안 처리 중 개별 면담을 구분해 보고서 1-3/2-4를 만드는 백엔드 화면이다. 기존 React 서류 4종 편집기는 유지한다. 두 보고서의 전체 편집 UI를 React 안에 다시 구현하지는 않는다.

## Vercel 기본값

Root Directory는 frontend, 빌드는 npm run build, 출력은 dist다. 서버 주소가 고정되면 아래 값으로 재배포한다.

```dotenv
VITE_API_BASE_URL=https://실제-백엔드-주소
VITE_USE_MOCK=false
```

키를 VITE_*에 넣지 않는다. 현재 탭의 연결 설정은 환경변수 기본값보다 우선한다. 환경변수를 바꾸면 재배포가 필요하고, 현재 탭의 설정은 즉시 적용된다.

백엔드는 https://hackathon-tau-mocha.vercel.app 및 로컬 localhost:5173·127.0.0.1:5173을 허용한다. 다른 Vercel Preview 주소는 별도 허용 없이는 CORS에 막힌다. 새 서류·전사의 교차 출처 쓰기는 기본 허용 범위가 아니므로 우선 작업실 링크에서 진행한다.

```bash
npm ci

```

계약 테스트는 인증 헤더 분리, 요청 본문·재시도 ID 유지, 잘못된 키의 연결 미확정, HTML 오류 처리, 키 비저장, 다른 서버로 키 전달 방지, 연결 변경 중 늦은 응답 무시를 포함한다. MSW의 별도 loopback 주소에서 네트워크 없이 실행하며 유료 추론을 하지 않는다.

이번 변경은 Node 24.22.1에서 린트·타입 검사·프로덕션 빌드와 계약 테스트 76개를 통과했다. 브라우저 자동 실행은 실행 환경의 Unix 소켓 제한으로 완료하지 못했다. 실제 LLM의 상담 품질이나 외부 음성 왕복 검증과 구분한다.

실제 src/lib/api.ts를 로컬 FastAPI 서버에 연결해 인증·상담 생성·위험 발언 3회 보고·동일 request_id 재시도·교사 요약·승인·초안 수정/검토/재조회·작업실 응답을 확인했다. 이 서버의 AI 모드는 mock이며 유료 모델 호출은 하지 않았다.
