고성능 상담 API 공유 서버

가상 학생 데이터로 상담·요약·위험 보고·서류 초안을 확인합니다.

API 테스트 / Swagger학교폭력 서류 초안 작업실위험 보고 확인함서버 상태

접속 방법

  1. API 테스트에서 Authorize를 누릅니다.
  2. 상담 API는 FrontendAccess, 교사 기록·서류·전사는 TeacherAccess에 담당자가 공유한 키를 입력합니다.
  3. 작업실과 위험 보고 확인함은 화면에서 교사 접속키를 입력합니다.

두 키는 별도로 전달받으세요. API 키를 입력하는 화면이 아닙니다. 임시 서버는 실행한 PC와 서버 창이 켜져 있는 동안만 사용할 수 있습니다.

팀 테스트 전용입니다. 상담 API의 학생·교사 화면은 하나의 가상 시연 공간을 공유하며 실제 사용자별 인증과 슈퍼스쿨 연동은 포함하지 않습니다. 실제 학생 정보나 녹음은 올리지 마세요. 실제 AI 호출에는 API 크레딧이 사용됩니다.
