학교 BAZE API 설정

  
API 키는 이 PC의 백엔드 .env에 저장합니다. 브라우저 저장소에는 보관하지 않습니다. 변경 사항은 새 상담부터 적용됩니다.

  
  
키는 이 주소의 게이트웨이에 전송됩니다. 학교 API 발급·설정 화면의 주소와 일치하는지 확인하세요.

  
  
  
  

  
학교 목록은 v6를 제공하지만 공개 STT 문서는 v5를 설명합니다. 실제 v6 호출이 거절되면 v5로 설정해 새 상담을 시작하세요. 자동으로 모델을 바꾸지는 않습니다.
