# 학부모 안내 챗봇 (가상 보호자 시연)

프론트 `/parent`, 교사 `/teacher/parent-inquiries`를 사용한다. 런처의 학부모 카드는 학생·교사 카드 아래, 시연 초기화 위에 있다.

## 안내와 데이터 범위

- 학교 안내, 다른 기관 관할, 교사 확인 필요, 답변 제한, 긴급의 다섯 유형을 구분한다.
- 준비한 10개 안내 카드는 공식 교육부·교육청·생활법령·기관 자료를 출처와 함께 표시한다. 지식 버전은 2026-11-14다.
- 명시적인 위험·개인정보 요청·판정 요청·공식 동의/취소는 규칙으로 먼저 처리한다. 긴급 문의는 외부 모델을 기다리지 않고 SQLite 교사 문의함에 등록한다.
- 일반 질문의 의도가 규칙에 맞지 않을 때만 `BAZE_QUALITY_MODEL`로 카드를 분류한다. 반환 카드 ID와 유형을 검증하고 답변 본문은 준비된 설명만 사용한다. 모델 실패·잘못된 카드면 교사 확인 안내를 한다. 법률 답변을 자유 생성하지 않는다.
- 분류 요청에는 질문만 전달하며 저장된 상담 기록·면담·진술·사안 자료는 전달하지 않는다. 연결 학생 이름과 흔한 연락처·학적 패턴을 가린다. 임의의 개인정보를 완벽하게 익명화하는 기능은 아니므로 가상 사례만 입력한다.
- 문의 요약은 원문 앞 350자의 발췌로 명시하며 교사는 원문을 펼쳐 확인한다. 긴급 여부는 전체 원문에서 확인한다.
- 두 보호자 체험 프로필은 가상 학생에 연결한다. 최초 접근 시 기존 시연 사안의 해당 역할 학생과 연결되며, 사안이 없으면 별도의 학부모 시연 사안을 사용한다. 본인 자녀의 진행 단계만 반환하며 상대 학생·원문 자료는 반환하지 않는다.
- 일반 문의는 교사 근무시간 기준 1~2일 내 답변 목표를 안내한다. 긴급 답변에는 이 대기 문구를 넣지 않는다. 내부 화면 알림은 실제 교사 확인·긴급전화·문자 발송을 뜻하지 않는다.
- 안심전화는 희망 회신 방식과 가상 번호를 기록하는 요청이다. 실제 통화·번호 가림 서비스는 연결하지 않았다.
- 채팅으로 자체해결 동의·심의 요청 취소를 접수하지 않는다. 정식 서식은 교사 안내를 받는다.
- 교사의 절차 공지 시연 기록으로 연결된 양측 가상 보호자에게 심의 요청·자체해결 종결 안내를 저장한다. 서류 초안 생성/승인만으로 공지를 발송하거나 절차를 결정하지 않는다.
- 인증 없는 MVP다. 보호자 체험 선택은 실서비스의 본인 확인·권한 분리를 대체하지 않는다.

## API 역할

| 경로 | 역할 |
| --- | --- |
| GET /api/parent/profiles | 가상 보호자 체험 선택지 |
| GET /api/parent/{actor_id}/workspace | 본인 자녀 단계·대화·내 문의·답변·공지 |
| POST /api/parent/{actor_id}/messages | 안내 질문과 분류, 긴급 시 내부 교사 알림 |
| POST /api/parent/{actor_id}/inquiries | 문의·원하는 도움·희망 답변 방식 접수 |
| GET /api/teacher/parent-inquiries | 교사 문의함·기관 안내 이력·연결 사안 |
| PATCH /api/teacher/parent-inquiries/{id} | 확인·처리 상태·관할 안내 완료 기록 |
| POST /api/teacher/parent-inquiries/{id}/replies | 교사 답변 저장, 보호자 화면 반영 |
| POST /api/teacher/parent-notices/{case_id}/events | 정식 절차 완료를 가정한 시연 공지 기록 |

`request_id`로 질문/문의 재전송을 중복 제거한다. 같은 ID의 다른 내용은 409다. 절차 공지는 사안·절차별 한 번만 저장한다.

SQLite에 `parent_demo_bindings`, `parent_guidance_turns`, `parent_inquiries`, `parent_notices`, `parent_procedure_events`를 보관한다. 시연 초기화 시 학부모 시연 데이터도 지우며 실제 상담 보관함은 유지한다.

## 실행·검증

기존 환경변수와 실행기를 그대로 사용한다. 코드 교체 후 공유 서버를 재시작한다. `/health`의 `parent_guidance_contract=parent-guidance-v1`로 적용 여부를 확인한다. 목 데이터 모드도 같은 API 경로로 동작한다.

`python -m unittest discover -s tests -v`는 외부 전송 없는 ASGI 테스트다. 학부모 분류·정보 범위·긴급 중복 방지·교사 답변·양측 공지·초기화·기존 사안 연결을 포함한다. 프론트 계약은 `src/test/parentGuidance.test.ts`에서 확인한다.
